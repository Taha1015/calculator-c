# 🧮 Calculator in C

A simple menu-driven calculator built using the C programming language.

## 📷 Screenshot

![Calculator](Calculator.png)

## 📌 Features

- Addition
- Subtraction
- Multiplication
- Division
- Square
- Cube
- Infinite Menu
- Division by Zero Validation

## 🛠 Technologies Used

- C
- GCC
- Git
- GitHub

## 📚 Concepts Used

- Functions
- Switch Statement
- Loops
- User Input
- Function Prototypes

## 🚀 How to Run

```bash
gcc main.c -o calculator
./calculator
```

### Windows (MinGW)

```bash
gcc main.c -o calculator.exe
calculator.exe
```
